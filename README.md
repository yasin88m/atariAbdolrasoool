# سبزینه — Attari Shop

فرانت‌اند نمایشی یک سایت عطاری با React + Vite.

## اجرا

```bash
npm install
npm run dev
```

سایت RTL و کاملاً responsive طراحی شده و هیچ بک‌اند، ورود، ثبت‌نام یا سبد خریدی ندارد.

## ساختار
- `src/main.jsx` — ساختار صفحه Home و داده‌های نمایشی
- `src/styles.css` — طراحی کامل و responsive


## پنل مدیریت
مسیر پنل: `#/admin`. منبع نهایی محصولات `public/products.json` است و تصاویر در `public/images` قرار می‌گیرند. در Chrome/Edge دسکتاپ می‌توان پوشه ریشه پروژه را از داخل پنل انتخاب کرد و فایل‌ها را مستقیم ذخیره کرد.
